## Traffic

**Area:** Computer vision.

**Concepts studied:** Convolutional neural networks and experimental comparison.

Recorded submission: **7/7 in check50** and **1.00 in style50**.

[Official assignment](https://cs50.harvard.edu/ai/projects/5/traffic/)

### Learning record

This project contributed to my study of computer vision. This portfolio documents the topic and activity results. Solution code and assessed files remain private in accordance with course rules.

### Experiments conducted

The comparison used 26,640 images, a stratified 60/40 training/test split, random seed 42, and ten epochs per architecture. The network with one convolutional layer achieved 97.08% test accuracy and 0.13310 test loss; the network with two convolutional layers and dropout achieved 98.64% accuracy and 0.05855 loss. The observed improvement was 1.56 percentage points. Depth and dropout changed together, so this comparison does not isolate the contribution of each change. The experiments ran on Linux with Python 3.12 and TensorFlow 2.16.
